# PEPPER-App - The frontend application for PEPPER

[PEPPER](https://github.com/FennerLabs/pepper) is a Python package to Predict Environmental Pollutant PERsistence.

The PEPPER-app provides an intuitive user interface to predict persistence endpoints from molecular structure.
To launch the app, run the following command from the pepper-app folder:

``streamlit run 💻_Home.py``

A new tab will open in your browser, running the PEPPER-app.

An online, publicly available version of [PEPPER-app](https://pepper-app.streamlit.app/) is hosted on Streamlit.
